# Drivers_of_Bilingual_Toddlers_Word_Learning

SCRIPTS DESCRIPTIONS

Scripts are labeled with the study they belong to, and the type of simulations or empirical models they include. 

`study_1_accumulator_simulations` : This script includes code for all the computational simulations in Study 1.

`study_2_english_monolingual_models`: This script includes the data cleaning, model comparison, and reporting of the English monolingual sample.

`study_2_french_monolingual_models`: This script includes the data cleaning, model comparison, and reporting of the French monolingual sample.

`study_2_bilingual_models`: This script includes the data cleaning, model comparison, and reporting of the English-French bilingual sample. Models for single-language (English and French), total word, and concept vocabularies are included here.

DATA FOLDER

This folder includes all the files used and produced by the scripts. Some files do not have a corresponding script, as they were accessed from online or laboratory archives. Most file names include the following labels:

`mono` : Contains monolingual data.

`eng` : Contains English data.

`fre` : Contains French data.

`vocabsize_by_time_df#` : Contains data generated by the computational simulation with its corresponding number.

`word_difficulty` : Contains the simulated word difficulty data used in the computational simulations.

FIGURES FOLDER

This folder includes the figures used in the manuscript.

MODELS FOLDER

This folder includes the models conducted in the `study_2` scripts. IMPORTANT NOTE: the files for the English monolingual models were too large to be stored in GitHub. These files can be found in the OSF project for this study [https://osf.io/u8jgh].

File names include the following labels:

`mono` : Model of monolingual data.

`bi` : Model of bilingual data.

`eng` : Model of English vocabulary data.

`fre` : Model of French vocabulary data.

`concept` : Model of concept vocabulary data.

`word` : Model of total word vocabulary data.

`scaled` : Model of standardized data when regular reporting functions were unable to provide standardized coefficients.
